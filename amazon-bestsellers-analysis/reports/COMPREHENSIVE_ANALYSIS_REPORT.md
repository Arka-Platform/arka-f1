## 9. Methodology & Data Quality

### 9.1 Data Sources

- **Source:** Amazon India Bestsellers (November)
- **Total Records:** 35,335 books
- **After Outlier Removal:** 31,173 books

### 9.2 Outlier Removal

Outliers were removed using the following criteria:
- **Price Range:** ₹50 - ₹5,000 (realistic book pricing for Indian market)
- **Review Count:** IQR method with 2.5×IQR upper bound, capped at 500,000
- **Rating Range:** 1.0 - 5.0 (valid rating scale)

### 9.3 Genre Classification

- Genres extracted from Amazon category links (category-link-0 through category-link-3)
- Sub-genres grouped within main genres for hierarchical analysis
- Category IDs mapped to genre names using verified mapping

### 9.4 Column Mapping

Verified column mappings:
- **data2:** Review/rating count
- **data3:** Book title
- **data4:** Format (Paperback, Hardcover, etc.)
- **data5:** Author name
- **data6:** Rank
- **data7:** Publisher name
