## 🔬 Research Methodologies Applied

### 1. **Descriptive Statistics**
   - Central tendency (mean, median, mode)
   - Dispersion (std dev, variance, range)
   - Distribution analysis (skewness, kurtosis)
   - Percentile analysis

### 2. **Inferential Statistics**
   - Pearson correlation analysis
   - Hypothesis testing (p-values)
   - Statistical significance testing
   - Confidence intervals

### 3. **Market Segmentation**
   - K-means clustering (k=4)
   - Feature standardization
   - Segment profiling
   - Market positioning

### 4. **Price Analysis**
   - Price distribution
   - Price range categorization
   - Market pricing patterns
   - Price elasticity indicators

### 5. **Rating & Review Analysis**
   - Rating distribution
   - Review count analysis
   - Quality indicators
   - Customer satisfaction metrics

### 6. **Format & Category Analysis**
   - Format preferences
   - Category distribution
   - Format-price relationships
   - Market trends

### 7. **Author & Publisher Analysis**
   - Top performers identification
   - Success metrics
   - Market share analysis
   - Performance rankings

## 🚀 Quick Start

### Option 1: Run Python Script
```bash
cd amazon-bestsellers-analysis
pip install -r requirements.txt
python scripts/data_analysis.py
```

### Option 2: Use Jupyter Notebook
```bash
cd amazon-bestsellers-analysis
pip install -r requirements.txt
jupyter notebook notebooks/01_comprehensive_analysis.ipynb
```
